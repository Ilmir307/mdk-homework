## 1. Цель работы

Освоить работу с Git и применить стандарты кодирования PEP 8 на примере простого Python-приложения, выводящего приветственное сообщение.

## 2. Код приложения

Файл [main.py](https://github.com/Ilmir307/hello-app/blob/main/main.py):

```python
"""Приветственное приложение (задание 1941)."""


def greet(name):
    """Возвращает приветствие для указанного имени."""
    return "Привет, " + name + "!"


def main():
    """Печатает приветствие."""
    print(greet("мир"))


if __name__ == "__main__":
    main()
```

Применённые правила PEP 8: docstring модуля и функций, snake_case, двойные пустые строки между функциями, защита точки входа. Проверка `pycodestyle` (современное имя инструмента pep8) — нарушений не выявлено. Запуск: программа выводит «Привет, мир!».

## 3. Логи Git-репозитория (список команд)

```text
git init -b main                      # создать репозиторий с веткой main
git add .                             # добавить файлы в индекс
git commit -m "Приветственное приложение main.py"   # первый коммит
git checkout -b feature/personal-greeting           # создать ветку и переключиться
git add . && git commit -m "Функция greet с параметром имени, docstring"
git checkout main                     # вернуться в основную ветку
git merge --no-ff feature/personal-greeting         # слияние изменений
git branch -d feature/personal-greeting             # удалить отработанную ветку
gh repo create hello-app --public --source=. --push # публикация на GitHub
git log --oneline --graph             # история
```

История после слияния:

```text
*   359e21e Слияние feature/personal-greeting в main
|\
| * c120b9d Функция greet с параметром имени, docstring
|/
* 3afc70c Приветственное приложение main.py
```
