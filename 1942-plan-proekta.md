# План организации работы команды разработчиков

**Проект: программный продукт «Система учёта заказов» · МДК 02.02 · группа 3424А**
**Презентация:** [1942-plan-proekta.pptx](1942-plan-proekta.pptx)

## 1. Цель плана

Разработать план организации работы команды для выполнения программного проекта: распределение задач, сроки, методы коммуникации и контроля, система отчётности.

## 4. Методы коммуникации и контроля

- **Ежедневный стендап** (15 минут) — статус и препятствия.
- **Доска задач** (Trello/GitHub Projects) — статусы «в работе / на проверке / готово».
- **Код-ревью** каждого pull request ведущим разработчиком.
- **Контроль сроков:** отставание задачи более чем на 2 дня — разбор на стендапе и перераспределение.
- **Контроль качества:** Definition of Done — код по PEP 8, модульные тесты, ревью пройдено.

## 5. Система отчётности

| Отчёт | Частота | Кому | Содержание |
|---|---|---|---|
| Статус на доске | Ежедневно | Команда | Состояние каждой задачи |
| Сводка руководству | Еженедельно | Руководство | Сделано/в работе/риски |
| Отчёт о тестировании | По фазам | Команда | Найденные и закрытые дефекты |
| Итоговый отчёт | Конец проекта | Заказчик | Соответствие ТЗ, метрики |

## 6. Вывод

План организации работы команды из пяти человек охватывает состав и роли, распределение восьми задач по срокам и ответственным с учётом навыков, методы коммуникации и контроля (стендапы, доска, ревью, Definition of Done) и систему отчётности с четырьмя регулярными отчётами. Общий срок проекта — 4,5 недели; резервные механизмы (перераспределение при отставании, контрольные точки) позволяют удержать план при отклонениях.
