# Работа с API и обмен данными между модулями

**МДК 02.02 · группа 3424А**

## 1. Цель и выбор инструментов

Цель — освоить инструменты работы с API и обмен данными между модулями. Выбрана библиотека **requests** (стандарт де-факто для HTTP в Python) и открытый тестовый API **JSONPlaceholder** (`https://jsonplaceholder.typicode.com`), поддерживающий методы GET и POST без авторизации.

## 2. Шаги выполнения

1. Изучены основы HTTP-методов: **GET** — получение данных без изменения состояния сервера, **POST** — создание новой сущности на сервере.
2. Проверена библиотека `requests` (уже установлена в окружении).
3. Разработана программа из трёх модулей:
   - [task1742_api_module.py](task1742_api_module.py) — `get_posts()` (GET /posts) и `create_post()` (POST /posts); `raise_for_status()` превращает HTTP-ошибки в исключения;
   - [task1742_processing_module.py](task1742_processing_module.py) — `count_posts_by_user()` и `make_summary()`: обработка полученных данных;
   - [task1742_main.py](task1742_main.py) — связывает модули: GET → обработка → вывод → POST.
4. Обмен данными между модулями: API-модуль возвращает список словарей из JSON, основной модуль передаёт его функциям обработки, результаты выводятся пользователю.
5. Выполнено тестирование (см. ниже); ошибки сети перехватываются (`requests.RequestException`) с понятным сообщением.

## 3. Результаты тестирования

```text
GET-запрос: получено публикаций: 100

Публикаций по пользователям:
  userId 1 -> 10
  userId 2 -> 10
  ... (все 10 пользователей по 10 публикаций)

Первые публикации:
1. sunt aut facere repellat provident occaecati excepturi optio reprehenderit
2. qui est esse
3. ea molestias quasi exercitationem repellat qui ipsa sit aut

POST-запрос: сервер вернул id = 101
Сервер сохранил заголовок: Учебный пост
```

GET вернул 100 публикаций и они корректно переданы модулю обработки (статистика по 10 пользователям и список заголовков); POST создал новую сущность — сервер ответил присвоенным id = 101 и вернул переданный заголовок. Код соответствует PEP 8 (проверено pycodestyle).

## 4. Вывод

Программа осваивает оба базовых метода HTTP: GET для получения данных и POST для их создания, а обмен между модулями организован через простые структуры данных без лишних зависимостей. Такая схема «модуль доступа → модуль обработки → основной модуль» позволяет заменить API или логику обработки независимо друг от друга.
