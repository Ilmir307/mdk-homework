## 1. Исходный код

Файл [task1226_original.py](task1226_original.py) — расчёт суммы заказа со скидкой:

```python
def calc(items,disc):
    total=0
    for i in items:
        total=total+i
    if disc==True:
        total=total-total*0.1
    else:
        total=total
    x = total
    print("Итого:",x)
    return x

data=[100,200,50]
print(calc(data,True))
```

## 2. Выявленные проблемы

1. **Ручной цикл суммирования** — вместо встроенной `sum()`: длиннее и медленнее для чтения.
2. **Магическое число 0.1** — размер скидки «зашит» в формулу; при изменении придётся искать по коду.
3. **Сравнение `disc == True`** — избыточно: условие само логическое.
4. **Пустая ветка `else: total = total`** — бесполезный код.
5. **Лишняя переменная `x`** — копия `total` без назначения.
6. **Смешение ответственности** — функция и считает, и печатает: её нельзя переиспользовать.
7. **Нарушения PEP 8** — имена `calc`, `data`, нет пробелов после запятых, нет docstring.

## 3. Предложенные улучшения и их обоснование

| Улучшение | Обоснование |
|---|---|
| Цикл заменён на `sum(prices)` | Встроенная функция короче, быстрее и понятнее |
| `DISCOUNT_RATE = 0.1` вынесено в константу | Размер скидки меняется в одном месте, имя объясняет число |
| `if with_discount:` вместо `== True` | Идиоматичный Python, ветка `else` удалена за ненужностью |
| Печать вынесена из расчёта в `main()` | Функция расчёта стала чистой — её можно тестировать и импортировать |
| Имена `calculate_total`, `prices`, `with_discount` | Самодокументируемый код без комментариев-переводов |
| Docstring и защита `__main__` | Соответствие PEP 8, модуль можно импортировать |
