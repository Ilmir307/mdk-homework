# Работа в системе контроля версий (на примере Git)

**МДК 02.02 · группа 3424А**
**Репозиторий:** [github.com/Ilmir307/git-basics-demo](https://github.com/Ilmir307/git-basics-demo)

## 1. Цель работы

Ознакомиться с основными функциями системы контроля версий Git и применить их для управления исходным кодом: clone, add, commit, push, pull, удаление файлов.

## 2. Описание выполненных команд и результатов

| Шаг | Команда | Результат |
|---|---|---|
| Создание репозитория | `gh repo create git-basics-demo --public --source=. --push` | Репозиторий создан на GitHub, локальная история отправлена |
| Инициализация | `git init -b main` | Создан локальный репозиторий с веткой main |
| Добавление в индекс | `git add .` | Файлы hello.py, calc.py, draft.txt подготовлены к коммиту |
| Коммит | `git commit -m "Добавлены hello.py, calc.py и draft.txt"` | Изменения зафиксированы |
| Изменение на GitHub | правка через веб-интерфейс (добавлен notes.md) | В удалённом репозитории появился новый коммит |
| Синхронизация | `git pull` | notes.md подтянулся в локальный репозиторий |
| Удаление файла | `git rm draft.txt` + `git commit` | Черновик удалён и зафиксирован |
| Отправка | `git push` | Удаление опубликовано на GitHub |
| Проверка истории | `git log --oneline` | Видна вся цепочка коммитов |

## 3. История репозитория

```text

```

*(Вместо снимков экрана: транскрипт команд и результатов выше + публичная история на GitHub — [страница коммитов](https://github.com/Ilmir307/git-basics-demo/commits/main), где видны все изменения, включая веб-правку и удаление файла.)*

## 4. Вывод

Освоен базовый цикл Git: создание репозитория, добавление и удаление файлов, коммиты, отправка на GitHub и, что важно для командной работы, — синхронизация через `git pull`, когда изменение сделано на удалённой стороне (веб-правка notes.md успешно подтянулась локально). История коммитов на GitHub подтверждает все шаги.
