## 2. Описание шагов работы

1. Создан репозиторий `my_repo` на GitHub и локальный репозиторий на компьютере.
2. Добавлен файл `example.py` (сумма двух чисел) — зафиксирован первым коммитом.
3. Файл доработан: добавлены docstring, функция `main`, защита `__main__` — второй коммит.
4. Добавлена функция `subtract_numbers` — третий коммит; изменения отправлены на GitHub командой `git push`.
5. Добавлен файл `main.py` с функцией `square` — четвёртый коммит.
6. В `main.py` добавлены функция `cube`, строки документации и оформление по PEP 8 — пятый коммит.
7. Код проверен инструментами автоматической проверки стандартов: `flake8` и `pycodestyle`.

## 4. Код с применёнными стандартами PEP 8

Файл [main.py](https://github.com/Ilmir307/my_repo/blob/main/main.py):

```python
"""Пример программы на Python по стандартам PEP 8 (задание 1668)."""


def square(number):
    """Возвращает квадрат числа."""
    return number * number


def cube(number):
    """Возвращает куб числа."""
    return number ** 3


def main():
    """Точка входа: демонстрирует работу функций."""
    print("Квадрат 7:", square(7))
    print("Куб 3:", cube(3))


if __name__ == "__main__":
    main()
```

Применённые правила PEP 8: имена функций в snake_case, две пустые строки между определениями функций, docstring у модуля и каждой функции, строки короче 79 символов, точка входа защищена блоком `if __name__ == "__main__":`.

## 5. Вывод

Код проверен инструментами flake8 и pycodestyle — нарушений PEP 8 не выявлено. История из пяти коммитов наглядно показывает поэтапное развитие кода: от простейшего скрипта до оформленной по стандартам программы с двумя функциями.
