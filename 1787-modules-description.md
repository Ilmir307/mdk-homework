# Интеграция программных модулей в Python

**МДК 02.02 · группа 3424А**

## 1. Цель и задача

Разработать модульную программу, демонстрирующую интеграцию программных модулей: чтение данных из файла, обработка, сохранение результатов в другой файл.

**Задача программы** ([task1787_word_frequency.py](task1787_word_frequency.py)) — частотный анализ текста: программа читает текст из файла, считает, сколько раз встречается каждое слово, и сохраняет частотный список в файл результата.

## 2. Использованные модули и их функции

Программа разбита на логические модули (секции с функциями), каждая функция имеет единственную ответственность:

| Модуль | Функция | Назначение |
|---|---|---|
| Чтение данных | `read_text` | Читает текст из входного файла в строку |
| Обработка данных | `count_words` | Считает частоту слов (без учёта регистра и знаков препинания) |
| Обработка данных | `sort_by_frequency` | Сортирует слова по убыванию частоты, при равенстве — по алфавиту |
| Сохранение | `save_result` | Записывает частотный список в файл результата |
| Основная часть | `main` | Связывает модули последовательно и обрабатывает ошибку отсутствия файла |

Интеграция выполнена последовательной композицией: выход `read_text` — вход `count_words`, выход `sort_by_frequency` — вход `save_result`. Код соответствует PEP 8 (проверено pycodestyle), функции снабжены docstring.

## 3. Результаты тестирования

Прогон на файле [task1787-text.txt](task1787-text.txt):

```text
Слов в тексте: 30
Уникальных слов: 25
Топ-3 частых слова: [('git', 4), ('а', 2), ('работать', 2)]
Результат сохранён в файл: task1787-result.txt
```

Файл результата [task1787-result.txt](task1787-result.txt) содержит частотный список всех слов. Проверен и сценарий ошибки: при отсутствии входного файла программа выводит понятное сообщение и не падает. Тестирование на разных входных данных (тексты разной длины) показало корректную работу.

## 4. Вывод

Программа демонстрирует модульный подход: задачи чтения, обработки и сохранения разделены по независимым функциям с понятными интерфейсами. Такая структура упрощает сопровождение и повторное использование: например, `count_words` можно импортировать в любой другой проект, а замена файлового ввода на ввод из сети затронет только модуль чтения.
