# Практическое задание по отладке программных модулей

**МДК 02.02 · группа 3424А**

## 1. Цель работы

Научиться выявлять и исправлять ошибки в коде на Python, используя методы и инструменты отладки.

**Инструменты отладки:** чтение трассировки (traceback), печать промежуточных значений, пошаговый отладчик `pdb` (точки останова, просмотр переменных), а также IDE-отладчик (VS Code / PyCharm).

## 2. Анализируемый код и найденные ошибки

Файл [task1605_buggy.py](task1605_buggy.py) — поиск максимума и среднего арифметического. Найдены три ошибки:

| № | Ошибка | Как обнаружена | Проявление |
|---|---|---|---|
| 1 | `find_max` стартует с `max_num = 0` | Печать промежуточного результата на отрицательном списке | `find_max([-5, -3])` возвращает 0 вместо −3 |
| 2 | Цикл `range(1, len(...))` пропускает первый элемент | Пошаговый проход в pdb: первый элемент никогда не сравнивается | `find_max([9, 1, 2])` возвращает 2 вместо 9 |
| 3 | `average` делит на `len(numbers)` без проверки | Трассировка: ZeroDivisionError на пустом списке | Аварийное падение программы |

**Методы отладки в действии:** ошибка №3 найдена чтением traceback (указана строка и тип исключения); ошибки №1–2 — прогоном на специально подобранных наборах (только отрицательные числа; максимум в первой позиции) и пошаговым просмотром значений `max_num` в отладчике.

## 3. Исправленный код

Файл [task1605_fixed.py](task1605_fixed.py): максимум инициализируется первым элементом, цикл идёт со второго; обе функции на пустом списке выбрасывают понятное `ValueError`. Код оформлен по PEP 8 (проверено pycodestyle).

## 4. Результаты тестирования исправленного кода

```text
Максимум: 8
Среднее: 4.25
Максимум отрицательных: -3
Максимум [9, 1, 2]: 9
Пустой список -> понятная ошибка: список пуст
Пустой список -> понятная ошибка: среднее пустого списка не определено
```

Все наборы, ломавшие исходную версию, после исправления дают верный результат; ошибочные входы обрабатываются понятным исключением вместо аварийного падения.

## 5. Вывод

Отработан полный цикл отладки: чтение трассировки, точечные прогоны на «ломающих» данных, пошаговый анализ в отладчике, исправление и регрессионная проверка. Найдены и устранены три ошибки: неверная инициализация максимума нулём, пропуск первого элемента и деление на ноль. Опыт показывает: большинство таких ошибок вскрывается не взглядом в код, а тестами на краевых случаях (пустой список, все отрицательные, экстремум на границе).
