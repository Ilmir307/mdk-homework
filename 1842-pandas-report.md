# Интеграция программных модулей в Python (pandas и numpy)

**МДК 02.02 · группа 3424А**

## 1. Цель работы

Разработать программу на Python, демонстрирующую интеграцию программных модулей: чтение данных из CSV, обработка со сторонними модулями pandas и numpy, сохранение результатов в другой CSV-файл.

## 2. Использованные модули

| Модуль | Тип | Для чего использован |
|---|---|---|
| `pandas` | Сторонний | Чтение CSV в DataFrame, вычисляемый столбец, группировка `groupby`, сортировка, запись CSV |
| `numpy` | Сторонний | Математические операции: среднее значение (`np.mean`), округление (`np.round`) |
| Стандартная библиотека | Встроенный | Обработка ошибки отсутствия файла |

Структура программы ([task1842_pandas_analysis.py](task1842_pandas_analysis.py)): точка входа `main()` последовательно связывает этапы: чтение CSV → добавление столбца выручки → группировка по товарам → расчёт среднего чека → сортировка → запись результата.

## 3. Результаты тестирования

Входной файл [task1842-sales.csv](task1842-sales.csv) (8 строк продаж). Запуск:

```text
    product  total_quantity  total_revenue  average_check
Флешка 64ГБ               6           5700          950.0
Кабель HDMI               3           2397          799.0
Коврик мыши               5           2250          450.0
      Тонер               6           2100          350.0

Всего выручка: 12447
Средняя цена продажи (numpy.mean): 624.75
Результат сохранён в файл: task1842-result.csv
```

Итоговый CSV [task1842-result.csv](task1842-result.csv) содержит агрегацию по товарам: штуки, выручка, средний чек — отсортировано по выручке. Проверена обработка ошибки: при отсутствии файла выводится понятное сообщение. Тестирование на другом наборе данных (изменённые количества и цены) дало корректную пересчитанную агрегацию. Код соответствует PEP 8 (pycodestyle).

## 4. Вывод

Программа демонстрирует интеграцию встроенных и сторонних модулей: pandas взял на себя табличную обработку (чтение, группировка, запись CSV), numpy — численные расчёты, что сократило код до одной читаемой функции-конвейера. Использование зрелых библиотек вместо «ручных» циклов по строкам CSV уменьшает и объём кода, и вероятность ошибок в нём.
